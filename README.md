# Werkstatt demo

Cuatro páginas de práctica con contenido de ejemplo, hechas para comparar enfoques de diseño web antes de definir los parámetros propios de Werkstatt.

| Carpeta | Enfoque |
|---|---|
| `taste-high-end/` | Método de la skill high-end-visual-design (Taste Skill) |
| `taste-brutalist/` | Método de la skill industrial-brutalist-ui (Taste Skill), modo Swiss Industrial Print |
| `impeccable/` | Guías de la skill Impeccable |
| `rediseno-demo-v1/` | Demo v1 mejorada con la auditoría de redesign-existing-projects (Taste Skill) |
